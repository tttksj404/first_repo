# /risk-audit — 리스크 관리 감사

트레이딩 봇의 리스크 관리 파라미터와 로직을 전수 검사합니다.

## 감사 항목

### 1. 포지션 사이징
- [ ] 단일 포지션 최대 자본 비율 설정 (권장: ≤ 5%)
- [ ] 동시 최대 포지션 수 제한 존재
- [ ] Kelly Criterion 또는 고정 비율 방식 명확히 정의됨
- [ ] 레버리지 상한선 설정 (권장: ≤ 5x 초보, ≤ 10x 중급)

### 2. 손절 / 이익실현
- [ ] 손절(Stop Loss) 모든 포지션에 적용
- [ ] 손절이 진입 즉시 설정됨 (사후 설정 금지)
- [ ] 트레일링 스탑 로직 버그 없음
- [ ] Take Profit 존재 (오픈 포지션 무한 보유 방지)

### 3. 일일/총 손실 한도
- [ ] 일일 최대 손실 한도 (`max_daily_loss`) 설정
- [ ] 한도 초과 시 봇 자동 정지 로직
- [ ] 드로다운 기반 포지션 축소 로직

### 4. API / 주문 안전장치
- [ ] 최대 주문 금액 상한선
- [ ] 중복 주문 방지 (idempotency key 또는 주문 상태 체크)
- [ ] API 에러 시 재시도 횟수 제한 (무한 루프 금지)
- [ ] Rate limit 처리 (429 에러 핸들링)

### 5. 비상 정지
- [ ] 긴급 전체 포지션 청산 기능 (`emergency_close_all`)
- [ ] 외부 신호로 봇 중지 가능 (파일 플래그 또는 API)
- [ ] 알림 시스템 (카카오톡, 텔레그램 등)
