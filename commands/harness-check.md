# /harness-check — 장기 실행 앱 상태 진단

Anthropic Harness Design 패턴 기반. 24/7 실행 봇의 컨텍스트·메모리·에이전트 상태 점검.

## 진단 항목

### 컨텍스트 상태
- 현재 세션이 얼마나 오래됐나?
- 컨텍스트 압축이 발생했나? (정보 손실 위험)
- 중요한 상태값이 메모리에 있나, 파일에 있나?

### 에이전트 분리 원칙 점검
Anthropic 권고 패턴:
- **Planner**: 전략 결정 (분리됨?)
- **Generator**: 주문 실행 (분리됨?)
- **Evaluator**: 성과 평가 (분리됨?)

단일 에이전트가 모두 담당하면 자기 평가 편향 발생 → 품질 저하

### 상태 영속성 확인
```bash
# 중요 상태가 파일로 저장되고 있는가?
ls -la state/
cat state/current_positions.json
cat state/session_context.json
```

### 컨텍스트 리셋 vs 압축 권고
| 상황 | 권고 |
|------|------|
| 새 전략 시작 | 컨텍스트 리셋 (새 세션) |
| 동일 전략 계속 | 구조화된 핸드오프 파일 사용 |
| 에러 디버깅 | 리셋 후 에러 컨텍스트만 주입 |

### 핸드오프 아티팩트 생성
현재 세션의 핵심 상태를 파일로 저장:
```json
{
  "session_id": "2026-03-27-001",
  "active_positions": [...],
  "last_signal": "...",
  "next_action": "...",
  "critical_context": "..."
}
```
