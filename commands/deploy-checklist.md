# /deploy-checklist — 실거래 투입 전 최종 체크리스트

봇을 실거래에 올리기 전 모든 항목을 검증합니다. 하나라도 ❌이면 투입 금지.

## 1단계: 전략 검증

- [ ] 백테스트 완료 (`/backtest-analyze` 통과)
- [ ] 테스트 기간 ≥ 1년 + 여러 시장 레짐 포함
- [ ] 샤프 비율 ≥ 1.0 (수수료 포함)
- [ ] 최대 드로다운 ≤ 20%
- [ ] 룩어헤드 바이어스 없음 확인
- [ ] 거래 횟수 ≥ 100회

## 2단계: 페이퍼 트레이딩

- [ ] 페이퍼 트레이딩 최소 2주 이상 실행
- [ ] 실제 거래소 API로 가상 오더 테스트 (Mock X, 실제 API O)
- [ ] 백테스트 대비 승률 차이 ≤ 10%
- [ ] 슬리피지 실측값 기록 완료
- [ ] 연결 끊김 후 재연결 시나리오 테스트 완료

## 3단계: 리스크 설정

- [ ] 단일 포지션 최대 자본 비율 설정 (≤ 5% 권장)
- [ ] 일일 최대 손실 한도 설정 (`max_daily_loss`)
- [ ] 손절 모든 포지션에 즉시 설정
- [ ] 레버리지 상한선 명시 (초보: ≤ 3x, 중급: ≤ 10x)
- [ ] 비상 전체 청산 기능 (`emergency_close_all`) 테스트 완료

## 4단계: 보안

- [ ] API 키 환경변수로 관리 (.env 또는 시스템 환경변수)
- [ ] API 키 코드/로그에 노출 없음
- [ ] **출금 권한 비활성화** (거래 권한만)
- [ ] IP 화이트리스트 설정
- [ ] `.env` 파일 `.gitignore`에 포함 확인

```bash
grep -r "api_key\s*=\s*['\"]" . --include="*.py"  # 하드코딩 탐지
grep "\.env" .gitignore  # gitignore 확인
```

## 5단계: 모니터링

- [ ] 알림 시스템 설정 (텔레그램 / 카카오톡)
- [ ] 에러 발생 시 알림 전송 테스트
- [ ] 봇 종료 시 알림 전송 테스트
- [ ] 로그 파일 자동 로테이션 설정
- [ ] 서버 재부팅 후 자동 시작 설정 (pm2 / systemd)

## 6단계: 실거래 초기

- [ ] **소액으로 시작** (전체 자본의 10% 이하)
- [ ] 첫 1주일은 매일 수동 확인
- [ ] 백테스트 대비 성과 주간 비교 (`/strategy-drift`)
- [ ] 2주 실거래 후 성과 정상이면 증액 검토

