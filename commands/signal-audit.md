# /signal-audit — 트레이드 신호 품질 분석 (학습 루프)

최근 N일의 실거래를 분석해서 전략 개선 포인트를 찾습니다.

## 사용법

```
/signal-audit                   # 최근 30일 분석
/signal-audit --days 14         # 최근 14일
/signal-audit --pair BTC/USDT   # 특정 페어만
/signal-audit --long-only       # 롱 트레이드만
```

## 분석 항목

### 1. 진입 품질 평가

각 트레이드의 진입 타이밍을 점수화:
```
최적 진입 대비 실제 진입 위치:
  상위 25% 진입  → ★★★ 최적 (신호 정확)
  25~50%         → ★★☆ 양호
  50~75%         → ★☆☆ 지연 진입 (신호 느림)
  하위 25%       → ☆☆☆ 최악 (신호 역방향)
```

### 2. 청산 품질 평가

```
TP 적중률    : TP까지 도달한 트레이드 비율
SL 적중률    : SL에 걸린 후 방향이 회복된 비율 (조기 청산 의심)
평균 보유시간 : 백테스트 평균 대비 ±30% 이내?
최대 미실현 익: 평균 TP의 몇 배까지 갔다 왔나
```

### 3. 레짐 적합성

최근 시장 상태를 자동 감지 후 전략 성과와 비교:
```
감지된 레짐  : 횡보 (ATR 낮음, BB 좁음)
레짐별 성과  :
  상승 트렌드 : 승률 68% (백테스트 71%) ✅
  하락 트렌드 : 승률 41% (백테스트 62%) ❌ 이탈
  횡보        : 승률 39% (백테스트 44%) ⚠️
```

### 4. 파라미터 드리프트 감지

```python
# 최근 30일 vs 백테스트 핵심 지표 비교
지표            백테스트    최근 30일    차이
승률             62%         54%         -8%  ⚠️
평균 수익(R)     1.8         1.2         -0.6 ❌
평균 손실(R)    -1.0        -1.3        -0.3 ⚠️
샤프(월간)       1.4         0.6         -0.8 ❌
```

### 5. 개선 제안 자동 생성

분석 결과에서 패턴을 찾아 구체적 제안:
```
발견: SL에 걸린 73%가 30분 내에 방향 회복
제안: SL을 현재보다 5~10% 넓히거나 시간 기반 청산 도입

발견: 09:00~11:00 UTC 진입 트레이드 성과 현저히 낮음
제안: 해당 시간대 필터 추가 검토

발견: 횡보장 승률 현저히 낮음
제안: ADX < 25 조건에서 진입 스킵 고려
```

## 출력 형식

```
SIGNAL AUDIT — 최근 30일 (2026-02-26 ~ 2026-03-27)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
총 트레이드   : 87회
승률          : 54% (백테스트 62%) ⚠️ -8%
수익 팩터     : 1.31 (백테스트 1.68) ❌
평균 진입 품질: ★★☆ (지연 진입 패턴)
TP 적중률     : 44%

개선 제안 3건:
  1. SL 범위 확대 (8% → 12%)
  2. 09:00~11:00 UTC 필터 추가
  3. 횡보 레짐 감지 로직 추가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
상태: ⚠️ 전략 재조정 권고
```
