# /bot-health — 트레이딩 봇 상태 확인

실행 중인 코인 매매 봇의 전반적인 상태를 점검합니다.

## 점검 항목

### 프로세스 상태
```bash
# 실행 여부 확인
ps aux | grep bot
# 또는 pm2 사용 시
pm2 status
pm2 logs bot --lines 50
```

### 최근 로그 분석
- 마지막 신호 수신 시간
- 마지막 주문 실행 시간
- 에러/경고 메시지
- API 연결 상태

### 포지션 확인
- 현재 오픈 포지션
- 미실현 손익 (PnL)
- 진입가 vs 현재가

### 자본 현황
- 사용 가능 잔고
- 포지션에 묶인 자본
- 오늘 실현 손익

### 시스템 리소스
```bash
# CPU / 메모리
top -p $(pgrep -f bot.py) -n 1
# 디스크
df -h
```

## 이상 징후 감지

- 마지막 신호 수신 > 설정 인터벌 × 3 → ⚠️ 경고
- 에러 로그 > 5건/시간 → 🔴 긴급
- 메모리 > 80% → ⚠️ 경고
- WebSocket 재연결 횟수 급증 → 🔴 연결 불안정
