# /trade-debug — 트레이드 이상 동작 디버깅

예상과 다른 주문, 포지션 불일치, 신호 누락 등을 체계적으로 추적합니다.

## 사용법

```
/trade-debug                    # 최근 이상 동작 전체 분석
/trade-debug order <주문ID>     # 특정 주문 추적
/trade-debug signal <시간>      # 특정 시간대 신호 재현
/trade-debug pnl                # PnL 계산 불일치 분석
```

## 디버깅 체크리스트

### 주문이 실행되지 않은 경우
1. 신호가 실제로 생성되었나? (로그 확인)
2. 필터 조건에 걸렸나? (포지션 한도, 시간 필터 등)
3. API 호출이 발생했나? (네트워크 로그)
4. 거래소가 에러를 반환했나? (잔고 부족, 최소 주문량 미달)
5. 주문이 생성됐지만 체결 안 됐나? (지정가 주문 미체결)

### 예상과 다른 주문이 실행된 경우
1. 중복 신호 발생 여부
2. 이전 미체결 주문이 뒤늦게 체결
3. 타임존 오프셋 문제
4. 캔들 완성 전 신호 계산 (lookahead)

### PnL이 예상과 다른 경우
1. 수수료 반영 여부
2. 슬리피지 반영 여부
3. 펀딩피 (선물 거래 시)
4. 부분 체결 처리
5. float 연산 오차

## 로그 분석 템플릿
