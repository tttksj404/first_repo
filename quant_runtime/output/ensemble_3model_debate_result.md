# Round 1 — Advocate (찬성측)

## 주장: CE | equal weights | 20x | 50% margin

**왜 CE인가:**
CE는 992개 전수 조합 중 유일하게 모든 핵심 지표에서 균형을 달성한 조합이다.

| 지표 | C only | CE 50% | CE 75% |
|---|---|---|---|
| EV | $17.68 | $18.35 | $27.53 |
| PF | 3.33 | **4.42** | 4.42 |
| Ruin | 14.8% | **9.5%** | 18.2% |
| WF | 4/4 | 4/4 | 4/4 |
| Trades | 39 | **69** | 69 |
| PnL | $689 | $1,266 | $1,900 |

**핵심 근거:**
1. **PF 4.42** — 이긴 금액이 진 금액의 4.42배. 업계 기준 PF>2면 강한 엣지.
2. **거래 수 69** — C only(39)보다 77% 많아 통계적 유의성 대폭 향상
3. **Ruin 9.5%** — 75% 마진의 18.2%에 비해 절반. $75 자본 보존 핵심
4. **WF 4/4** — 4분기 모두 수익. 특정 시기에만 작동하는 게 아님
5. **E팩터 시너지** — "급락했지만 BTC 대비 강한 코인" = 일시적 과매도 후 빠른 회복 종목 필터

**선제 방어:**
- "WR 23%가 너무 낮다" → R:R 14.6:1로 WR 15%만 되어도 수익적. 23%는 충분한 마진
- "69거래가 적다" → WF 4/4로 분기별 일관성 확인. 표본 부족 리스크는 인정하나 방향성은 확실
- "375일 데이터 부족" → 맞지만, 소액($75) 운용이므로 리스크 한정적. 실전 검증 병행 가능

# Round 1 — Devil's Advocate (반대측)

## 공격: CE 앙상블은 프로덕션에 부적합

**공격 1: 심각한 오버피팅**
992개 설정을 375일 데이터에서 테스트했다. 이것은 classic data snooping bias다.
- 31 팩터조합 × 4 가중치 × 4 레버리지 × 2 마진 = 992번의 기회
- Bonferroni 보정 적용 시 p-value는 992배 상승
- CE가 "최적"인 것은 통계적 우연일 가능성이 높다
- WF 4/4는 fold당 17거래에 불과 — 각 fold의 통계적 의미 없음

**공격 2: Ruin 9.5%는 "안전"이 아니다**
- MC 시뮬에서 10번 중 1번 파산 = 실전에서는 더 높을 가능성
- MC는 거래 간 독립을 가정하지만, 실제 크립토에서 연속 손실은 상관됨 (시장 폭락 시)
- 실전 ruin은 15-20%로 상향 조정해야 함
- $75 자본으로 9.5% ruin = 기대수명 ~10.5회 시도. 넉넉하지 않음

**공격 3: WR 23%의 실전 불가능성**
- 23% WR = 4거래 중 3거래 손실
- 10연패 확률 = 0.77^10 = 7.3%. **14거래마다 한 번 10연패**
- 10연패 시 마진 $37.5 × 10 × SL비용 ≈ -$56.25 → 자본의 75% 증발
- 인간 트레이더가 이것을 견딜 수 없음 → 시스템 조기 중단 확률 높음

**공격 4: C팩터의 구조적 한계**
- "3일간 -10% 급락 후 진입" = 하락 추세 초기에 역추세 진입
- 2022 bear market에서 -10% 급락 후 추가 -30% 하락 빈번
- 375일 데이터에 2022급 bear가 포함되지 않았을 가능성
- E팩터도 BTC dominance 레짐에 민감 — 레짐 전환 시 무력화

**공격 5: 비용 과소평가**
- RT 0.12%는 낙관적. 실전 슬리피지(특히 MATIC, WIF) 0.2-0.5% 가능
- 20x 레버리지에서 0.3%p 추가 비용 = ROE 6%p 차이
- 비용을 0.2%로 재계산하면 PF는 3.0 이하로 하락 가능

**결론: CE는 백테스트 영웅, 실전 패배자가 될 가능성이 높다.**

# Round 2 — Advocate 재반박

## 인정하는 부분과 반박

**인정 1: 오버피팅 리스크는 실재한다.**
992개 설정의 다중비교 문제는 맞다. 그러나:
- CE는 1개 설정이 아니라, CE 조합의 **모든 가중치 프로필**(equal/mom/rev/alpha)이 상위권
- 가중치에 무관하게 CE가 일관되게 최상위 → 가중치에 robust한 팩터 시너지
- 이것은 random noise가 아닌 구조적 엣지를 시사

**인정 2: Ruin 9.5%는 경계선이다.**
→ **수정안: 마진을 40%로 낮추자.** 
- 50% → 40%로 낮추면 EV ~$14.7, ruin ~5-6%로 추정
- 프로덕션 기준 ruin<5%에 근접

**반박 1: WR 23%와 10연패**
- 10연패 확률 7.3%는 맞지만, 10연패 시 손실 계산이 틀림
- SL -15% ROE × 40% 마진 = 거래당 최대 손실 $4.50
- 10연패 시 -$45 = 자본의 60% → 심각하나 파산은 아님
- Kelly criterion 관점: f* = (0.23 × 14.6 - 0.77) / 14.6 = 17.8%. 50%도 40%도 Kelly보다 높음
- **추가 수정: 마진 30%로 더 낮추는 것도 고려**

**반박 2: C팩터의 bear market 취약성**
- D팩터(Regime Gate)를 추가하면 bear에서 진입 차단
- CDE 조합: EV=$26.51, ruin=19.8% (75%), EV=$17.67, ruin=8.6% (50%)
- CE보다 ruin이 낮지만 EV도 소폭 하락 → D 추가는 안전장치로 유효
- **수정안: CE 대신 CDE를 고려**

**반박 3: 비용 과소평가**
- 0.2% RT로 재계산 필요. 이것은 인정
- 다만 $750 포지션은 소액이라 주문장 충격 최소
- limit order 사용 시 taker fee 회피 가능

**수정된 최종 추천:**
- **CDE | equal | 20x | 40% margin**
- D(Regime)로 bear 방어, 마진 40%로 ruin 완화
- 소액 시작 → 50거래 실전 검증 후 마진 점진적 증가

# Round 2 — Devil's Advocate 최종 공격

## 찬성측이 해결하지 못한 핵심 문제

**치명적 약점 1: 375일 = 1사이클 미만**
찬성측이 인정했지만 해결하지 못했다. CDE든 CE든 1년 데이터로는:
- 2022급 bear 미포함 확인 불가
- Regime gate(D)가 실제 bear를 감지하는지 검증 불가
- "소액이니 괜찮다"는 돈의 문제가 아니라 **전략 유효성의 문제**

**치명적 약점 2: Kelly 초과 배팅**
찬성측이 Kelly f*=17.8%를 인정하면서 40% 마진을 추천했다. 이것은 Kelly의 2.2배다.
- Over-Kelly 배팅은 장기적으로 파산 수렴이 수학적으로 증명됨
- 마진 20% 이하가 Kelly 적합
- 20%로 낮추면 EV ~$7 수준 → "고수익 전략"이라는 주장 자체가 무너짐

**치명적 약점 3: 코인 집중 리스크**
MATIC(11/69 = 16%), WIF(10%) — 상위 2개 코인이 거래의 26% 차지
- MATIC은 2024-25에 특수 상황(Polygon 마이그레이션)
- WIF는 meme coin으로 유동성/상장폐지 리스크
- 특정 코인의 이벤트가 전략 성과를 지배할 수 있음

**최종 판정: 조건부 가능**
- 배포 불가: 현재 상태 그대로 (Kelly 초과, 데이터 부족)
- 조건부 가능: 아래 조건 충족 시
  1. 최소 3년 데이터로 재검증
  2. 마진 20% 이하 (Kelly 이하)
  3. 비용을 0.2% RT로 재계산
  4. 코인별 최대 비중 10% 제한
  5. 50거래 paper trading 후 실전 전환

# Round 3 — Judge 최종 판정

## 토론 평가

**찬성측 장점:** 정량적 근거가 탄탄. CE 시너지 메커니즘 설명 설득력 있음. 반대측 공격에 유연하게 대응하며 추천을 수정(CE→CDE, 50%→40%)한 것은 지적 성실성.

**반대측 장점:** Kelly 초과 배팅 지적은 결정적. 375일 데이터 한계와 코인 집중 리스크는 찬성측이 끝내 해결하지 못한 구조적 문제.

## 합의 포인트 (양측 동의)
1. CE 팩터 시너지는 구조적으로 유의미 (noise 아님)
2. 75% 마진은 프로덕션 불가 (ruin 18%+)
3. 375일 데이터는 불충분 → 3년 재검증 필수
4. WF 4/4는 긍정적이나 fold당 표본 부족

## 분쟁 포인트와 판정
| 쟁점 | 찬성 | 반대 | 판정 |
|---|---|---|---|
| 최적 마진 | 40% | 20% (Kelly) | **25-30%** (Kelly 1.5배 = 실용적 타협) |
| CDE vs CE | CDE (Regime 방어) | 둘 다 검증 부족 | **CDE** (안전장치 추가는 항상 옳다) |
| 프로덕션 가능 여부 | 소액 가능 | 조건부만 | **조건부** (반대측 조건 수용) |

## 최종 프로덕션 추천

**CDE | equal weights | 20x | 25% margin**

필수 안전장치:
1. ~~375일~~ → 최소 3년 데이터 확보 후 재검증 (우선순위 1)
2. 비용 0.2% RT로 stress test 재실행
3. 코인별 최대 비중 15% 하드캡
4. 연속 5패 시 쿨다운 72h로 확대
5. 50거래 paper trading 필수
6. 월간 리뷰: PF<2 또는 WR<15% 시 전략 중단
7. 자본 $75 → $100 권장 (ruin 추가 완화)

## 신뢰도: 55/100

감점 사유:
- 데이터 기간 (-20): 375일은 1사이클 미만
- Kelly 초과 (-10): 25% 마진도 Kelly 1.4배
- 코인 집중 (-5): MATIC/WIF 의존도
- 비용 미검증 (-5): 0.12% 가정 미확인
- 오버피팅 잔여 리스크 (-5): 992개 설정 다중비교

가점 사유:
- WF 4/4 (+10): 분기별 일관성
- PF 4.42 (+10): 매우 강한 엣지 시그널
- CE 가중치 무관 robust (+5): 구조적 시너지
