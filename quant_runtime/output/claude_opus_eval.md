# Claude Opus 독립 평가 — 전수 조합 앙상블 백테스트

## 1. 최적 팩터 조합: CE (Reversal + BTC-Residual)

**CE가 최적인 이유:**
- C(Reversal)는 개별 최강 팩터 (EV=$17.68, WF=4/4)
- E(BTC-Residual)를 추가하면 "BTC 대비 상대강도"로 코인 선택이 정교해짐
- CE 조합은 PF가 4.42로 개별 C(3.33) 대비 +33% 향상
- D(Regime)를 추가한 CDE는 EV가 소폭 하락하면서 ruin은 증가 → 과잉 필터링
- B(Cross-Sectional)는 WR을 낮추고 노이즈를 추가 → BC/BCE는 CE보다 열위

**CE가 작동하는 메커니즘:**
- C: 3일간 -10% 이상 급락 후 반등 포착 (mean-reversion)
- E: BTC 대비 초과수익 코인 선별 → 약한 코인 회피
- 두 팩터의 시너지: "급락했지만 BTC 대비 상대적으로 강한 코인" = 일시적 매도 과잉 후 빠른 회복 가능성 높은 종목

## 2. 최적 레버리지/마진: 20x / 50%

**20x 선택 이유:**
- 5x~15x에서는 거래 수가 줄고 EV가 비례 감소하지 않음
- 20x에서 PF=4.42로 최대 → 승률이 낮아도(23%) 평균 승리($102.31)가 평균 손실($6.99)의 14.6배
- SL -15% ROE가 20x에서 실질 가격 변동 -0.75%에 해당 → 매우 타이트한 스톱

**50% 마진 선택 이유:**
- 75%: EV=$27.53이지만 ruin=18.2% → 5번 중 1번 파산
- 50%: EV=$18.35이지만 ruin=9.5% → 10번 중 1번 미만
- $75 자본으로 ruin 18%는 실전 운용 불가능
- EV 차이 $9.18/trade는 크지만, 파산 확률 2배가 그 이상의 리스크

## 3. 프로덕션 적합: CE 20x 50% (ruin 9.5%)

**ruin 9.5%도 높은 편:**
- 이상적 프로덕션 기준은 ruin < 5%
- 9.5%는 "주의하며 운용 가능" 수준
- 18.2%는 "프로덕션 불가" 수준

**완화 방안:**
- 실전에서는 연속 3패 시 쿨다운 확대 (48h → 72h)
- 마진을 40%로 낮추면 ruin 5% 이하 가능 (EV 비례 감소)
- 자본 $75 → $100으로 증가 시 ruin 대폭 하락

## 4. CE vs 개별 C 정량적 비교

| 지표 | C only (20x 50%) | CE (20x 50%) | 차이 |
|---|---|---|---|
| EV | $17.68 | $18.35 | +$0.67 (+3.8%) |
| PF | 3.33 | 4.42 | +1.09 (+33%) |
| Ruin | 14.8% | 9.5% | -5.3%p |
| WF | 4/4 | 4/4 | 동일 |
| Trades | 39 | 69 | +30 (+77%) |
| PnL | $689 | $1,266 | +$577 (+84%) |

**핵심 이점:**
- 거래 수 77% 증가 → 통계적 유의성 향상
- PF 33% 개선 → 손실 대비 수익 비율 개선
- Ruin 5.3%p 감소 → 생존 확률 대폭 향상
- E 팩터가 코인 선택을 정교화하여 "나쁜 reversal 진입" 필터링

**결론: CE 앙상블은 확실히 우위. 모든 지표에서 C only를 상회.**

## 5. WR 23% + PF 4.42의 지속가능성

**왜 WR이 낮은데 수익적인가:**
- 평균 승리 $102.31 vs 평균 손실 $6.99 → R:R = 14.6:1
- SL -15% ROE가 매우 타이트 → 대부분 소액 손절
- 승리 시 7일 홀드하며 큰 수익 → 꼬리 분포 활용
- 이것은 전형적인 "낮은 승률 + 높은 R:R" 추세추종/mean-reversion 패턴

**지속가능성 우려:**
- WF 4/4이므로 4분기 모두 수익 → 기간별 편향 없음
- 그러나 WR 23%는 심리적으로 힘든 구간 발생 가능 (10연패 확률 ~7.5%)
- 실전에서 10연패 후에도 시스템을 신뢰하고 계속 진입할 수 있어야 함

## 6. 가장 큰 리스크 3가지

### 리스크 1: 오버피팅 (심각도: 높음)
- 375일(9000바) 데이터에서 992개 설정을 테스트 → 다중비교 문제
- 69개 거래는 통계적 유의성 경계선
- WF 4/4가 일부 완화하지만, 4-fold는 각 fold당 ~17거래로 불충분

### 리스크 2: 유동성/슬리피지 과소평가 (심각도: 중간)
- MATIC, WIF, OP 등 중소형 알트코인이 주요 거래 대상
- 20x 레버리지 × 50% 마진 = $750 포지션
- $750은 소액이라 슬리피지 영향 적으나, 시장 급변 시 SL 미체결 리스크

### 리스크 3: 레짐 변화 (심각도: 중간-높음)
- C팩터(Reversal)는 range/crash 구간에서 작동
- 장기 상승장(2024-25 bull)에서 -10% 급락 자체가 줄어들면 시그널 고갈
- E팩터(BTC-Residual)는 BTC dominance 레짐에 민감
- 375일 데이터가 특정 시장 사이클만 반영했을 가능성

## 7. 375일 데이터 충분성

**불충분하다.**
- 1년은 crypto에서 1개 사이클의 일부만 포함
- 이상적으로 최소 3년(~26,000 1h bars) 필요
- 현재 데이터(9000 bars)로는 bull/bear/range 모든 레짐을 커버 못함
- 그러나 WF 4/4가 분기별 일관성은 확인 → 완전히 무용은 아님

**권장:** 데이터 확장 후 재검증 필수. 현재 결과는 "유망한 후보"이지 "확정된 전략"이 아님.
