## 🚀 문제 및 상세 해설

### 1. 서비스 중단 복구 시간 (RTO)
*   **정답:** **RTO (Recovery Time Objective / 복구 목표 시간)**
*   **이유:** 비상사태 또는 업무 중단 시점부터 업무가 복구되어 다시 정상 가동될 때까지의 **시간적 목표**를 의미하기 때문입니다.
*   **연결 개념:** 
    *   **RPO (Recovery Point Objective):** 복구 목표 지점 (데이터 손실 허용 시점).
    *   **MTTR (Mean Time To Repair):** 평균 수리 시간.

---

### 2. 파이썬 Set(집합) 연산 결과
*   **정답:** `{'중국', '태국', '베트남', '한국', '홍콩'}` (순서 무관)
*   **이유:** 
    1.  `add('중국')`: 집합은 중복을 허용하지 않으므로 변화 없음.
    2.  `remove('일본')`: 기존 요소 제거.
    3.  `update(['홍콩','한국','태국'])`: 리스트의 요소를 합집합 연산함. '한국'은 중복이므로 그대로 유지.
*   **연결 개념:** 파이썬의 `set`은 순서가 없고 중복을 허용하지 않는 자료구조입니다.

---

### 3. 웹 비동기 통신 기술 (AJAX)
*   **정답:** **AJAX (Asynchronous JavaScript and XML)**
*   **이유:** 전체 페이지를 새로고침하지 않고 브라우저의 `XMLHttpRequest` 객체를 이용해 일부 데이터만 로드하는 기술이기 때문입니다.
*   **연결 개념:** 
    *   **JSON (JavaScript Object Notation):** 최근 AJAX에서 데이터 교환 형식으로 XML 대신 주로 사용됨.

---

### 4. 경량 개발방법론 (Agile)
*   **정답:** **애자일 (Agile)**
*   **이유:** 사람 중심, 변화에 유연, 짧은 개발 주기(Iterative) 등을 특징으로 하며 폭포수(Waterfall) 모델과 대비되는 방법론이기 때문입니다.
*   **연결 개념:** **XP (Extreme Programming), Scrum, Kanban, Lean** 등이 애자일에 속함.

---

### 5. 자바 객체 생성 키워드
*   **정답:** **new**
*   **이유:** 자바에서 클래스의 인스턴스(객체)를 동적으로 메모리에 할당(생성)할 때 사용하는 예약어입니다.
*   **연결 개념:** `Parent pa = new Child();`는 **업캐스팅(Upcasting)**을 의미하며, 다형성을 구현하는 기초입니다.

---

### 6. SQL IN 연산자 활용
*   **정답:** `SELECT 학번, 이름 FROM 학생 WHERE 학년 IN (3, 4);`
*   **이유:** 특정 속성값이 리스트 내에 포함된 데이터를 조회할 때 `IN` 연산자를 사용합니다.
*   **연결 개념:** `OR` 연산자로도 표현 가능 (`학년 = 3 OR 학년 = 4`).

---

### 7. 트랜잭션 롤백 (Rollback)
*   **정답:** **트랜잭션 실행 중 오류가 발생했을 때, 지금까지 수행한 작업을 취소하고 이전의 정상 상태(Commit 지점)로 되돌리는 작업.**
*   **이유:** 데이터베이스의 원자성(Atomicity)을 보장하기 위한 핵심 메커니즘이기 때문입니다.
*   **연결 개념:** 
    *   **Commit:** 작업을 최종 승인하고 반영하는 것.
    *   **ACID:** 트랜잭션의 4대 속성 (원자성, 일관성, 고립성, 지속성).

---

### 8. 네트워크 계층 보안 프로토콜
*   **정답:** **IPSec (IP Security)**
*   **이유:** IP 계층(3계층)에서 무결성/인증(AH)과 기밀성(ESP)을 보장하는 표준 보안 프로토콜이기 때문입니다.
*   **연결 개념:** 
    *   **AH (Authentication Header):** 인증 및 무결성.
    *   **ESP (Encapsulating Security Payload):** 암호화 및 기밀성.

---

### 9. 정적 분석 도구 (Static Analysis)
*   **정답:** **정적 분석 도구 (Static Analysis Tool)**
*   **이유:** 프로그램을 **실행하지 않고** 소스 코드 자체를 분석하여 결함, 코딩 표준 준수 여부를 확인하기 때문입니다.
*   **연결 개념:** 
    *   **동적 분석(Dynamic Analysis):** 실행하면서 분석.
    *   **도구 예시:** SonarQube, PMD, Checkstyle.

---

### 10. 옵저버 패턴 (Observer Pattern)
*   **정답:** **Observer Pattern**
*   **이유:** 한 객체의 상태 변화가 있을 때 의존하는 다른 객체들에게 자동으로 통지되고 갱신되는 1:N 의존 관계 디자인 패턴이기 때문입니다.
*   **연결 개념:** 발행-구독(Publish-Subscribe) 모델과 유사하며, 느슨한 결합(Loose Coupling)을 지향합니다.

### 11. 리눅스 기반 모바일 운영체제
*   **정답:** **안드로이드 (Android)**
*   **이유:** 구글 주도의 리눅스 커널 기반 모바일 OS이며, 자바/코틀린을 사용하고 런타임 라이브러리를 제공하기 때문입니다.
*   **연결 개념:** **ART (Android Runtime), Dalvik VM.**

### 12. SQL 인덱스 생성
*   **정답:** `CREATE INDEX IDX_NAME ON 학생(NAME);`
*   **이유:** 인덱스 생성 문법은 `CREATE INDEX [인덱스명] ON [테이블명]([속성명]);` 입니다.
*   **연결 개념:** 검색 속도 향상이 목적이나, 삽입/삭제 시 성능 저하가 발생할 수 있음.

### 13. XML 기반 통신 프로토콜 (SOAP)
*   **정답:** **SOAP (Simple Object Access Protocol)**
*   **이유:** HTTP/SMTP 등을 통해 XML 기반 데이터를 교환하는 프로토콜이며, 최근에는 가벼운 RESTful 방식이 이를 대체하고 있기 때문입니다.
*   **연결 개념:** **WSDL (Web Services Description Language), UDDI.**

### 14. SQL Injection 정의
*   **정답:** **사용자의 입력란에 악의적인 SQL 구문을 삽입하여, 데이터베이스의 정보를 유출하거나 조작하는 공격 기법.**
*   **이유:** 애플리케이션의 보안 취약점을 이용해 DB 쿼리를 변조하기 때문입니다.
*   **연결 개념:** **Prepared Statement** 사용을 통해 방어 가능.

### 15. 리눅스 권한 설정 (chmod)
*   **정답:** `chmod 751 a.txt`
*   **이유:** 
    *   사용자(Read/Write/Exec): 4+2+1 = **7**
    *   그룹(Read/Exec): 4+1 = **5**
    *   기타(Exec): 1 = **1**
*   **연결 개념:** 4(r), 2(w), 1(x)의 조합.

---

### 16. UI 설계 원칙 (유효성)
*   **정답:** **유효성 (Effectiveness)**
*   **이유:** 사용자의 목적을 정확하고 완벽하게 달성할 수 있도록 하는 것이 유효성의 정의이기 때문입니다.
*   **연결 개념:** UI 4대 원칙 - **직관성, 유효성, 학습성, 유연성.**

---

### 17. 링크드 오픈 데이터 (LOD)
*   **정답:** **LOD (Linked Open Data)**
*   **이유:** 웹상의 데이터를 개별적으로 존재시키지 않고 서로 링크하여 하나의 거대한 데이터베이스처럼 활용하는 방식이기 때문입니다.
*   **연결 개념:** **Semantic Web (시맨틱 웹), URI, RDF.**

### 18. 데이터 모델링 절차
*   **정답:** **1. 개념적 데이터 모델링 -> 2. 논리적 데이터 모델링 -> 3. 물리적 데이터 모델링**
*   **이유:** 추상적인 개념(ERD)에서 시작하여 구조(정규화)를 잡고, 실제 저장 장치에 최적화(인덱스 등)하는 순서이기 때문입니다.
*   **연결 개념:** 
    *   개념: ERD
    *   논리: 정규화, 테이블 설계
    *   물리: 반정규화, 파티션, 인덱스

### 19. 자바 상속 및 생성자 출력 결과
*   **정답:** `a=10`
*   **이유:** 
    1.  `new B(10)` 호출 시 자식 클래스 생성자 실행.
    2.  `super(10)`에 의해 부모 클래스 A의 생성자가 호출되어 `a`에 10 저장.
    3.  `super.display()`에 의해 부모 클래스의 `display()` 메서드가 실행되어 "a=10" 출력.
*   **연결 개념:** **super** 키워드는 부모 클래스의 멤버에 접근할 때 사용함.
